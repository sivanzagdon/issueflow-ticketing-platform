# AI Workflow

This project was implemented using an AI-assisted engineering workflow.

Model used:
- GPT-5.5 Thinking
- Cursor AI agent

Workflow principles:
- Plan before coding.
- Reduce scope into small vertical slices.
- Keep the backend runnable after every slice.
- Implement the smallest correct version first.
- Avoid overengineering.
- Use AI for planning, code review, edge-case discovery, and test suggestions.
- Human review was applied to all generated code.
- I remain fully accountable for the submitted implementation.

The AI agent was not used as a replacement for understanding the system.
It was used as a development assistant under explicit project rules and architecture constraints.
